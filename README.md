# PulseScope — Medical Wearables Intelligence Dashboard

A source-linked global medical wearables dashboard for devices, health and wellness tracking, new technologies, FDA/CDSCO/EU MDR updates, and medical-device acquisitions.

The site will be published at **https://drmani1.github.io/pulsescope-dashboard/** once GitHub Pages is enabled under Settings → Pages → Source: GitHub Actions.

The data archive `data/briefings.json` preserves dated history. The dashboard exports CSV and JSON. The daily ChatGPT research briefing is separate from publishing; a workflow or repository update must write verified new items to the archive for the hosted site to reflect them.

This repository is public. Do not upload confidential data.
